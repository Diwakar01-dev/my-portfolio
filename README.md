##  Run Locally

Clone this repository:

```bash
git clone https://github.com/Diwakar01-dev/my-portfolio.git
```

Navigate to the project:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
